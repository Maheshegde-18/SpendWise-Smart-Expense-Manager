# Application Screenshots

Place genuine screenshots captured from the running SpendWise application (`http://localhost:5173`) in this directory.

## Recommended Screenshots to Capture

| Filename | View / Feature to Capture |
|---|---|
| `dashboard.png` | Main Dashboard showing the 4 summary cards, Credit Card widget, Transaction Overview area chart, Expense Breakdown donut chart, Recent Transactions list, and AI Assistant widget |
| `transactions.png` | Full Transactions Ledger page with summary metrics and inline search |
| `add-transaction.png` | Add Transaction modal (`TransactionModal`) with Income/Expense type switcher and form fields |
| `edit-transaction.png` | Edit Transaction modal pre-populated with an existing transaction record |
| `income.png` | Income Operations view (`defaultType="income"`) |
| `expenses.png` | Expense Operations view (`defaultType="expense"`) |
| `reports.png` | Reports and Analytics 3-column page (Revenue bar chart, Spending Limit, Weekly Expense bubbles, Daily Expense stacked bars, Saving Goal gauge) |

## How to Link Screenshots in `README.md`

Once you save the PNG files in `docs/screenshots/`, embed them in the root `README.md` under **Application Screenshots** using standard Markdown syntax:

```markdown
![SpendWise Dashboard](docs/screenshots/dashboard.png)
```
